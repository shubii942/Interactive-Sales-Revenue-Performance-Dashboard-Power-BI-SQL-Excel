# Interactive-Sales-Revenue-Performance-Dashboard-Power-BI-SQL-Excel
Tech Stack & Tools
• Power BI: Interactive visual dashboarding, DAX measures, and performance tracking.
• SQL (MySQL): Query writing, aggregations, and business logic data extraction.
• Python: Automated data processing and database import scripts.
• Excel: Raw data staging, data cleaning, and initial inspection.
💡 Key Business Insights
• Net Revenue Analysis: Evaluated $6.02M in total net sales across multiple channels.
• Profitability Margins: Identified high-margin product lines to optimize inventory strategy.
• Regional Highlights: Isolated key growth zones and geographical performance drivers.
